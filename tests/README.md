# Tests

Er is nog geen volwaardige geautomatiseerde teststack ingericht. Deze map blijft
bedoeld voor de eerstvolgende testbasis met regressietests voor:

- voorstellen accepteren/weigeren;
- Mijn dag als persoonlijke werkelijkheid;
- Planning als gemeenschappelijke werkelijkheid;
- RLS-zichtbaarheid per profiel, groep en gastcontext.

Zie `docs/audits/stability-cleanup-round-v0.1.md` voor het actuele testplan.
