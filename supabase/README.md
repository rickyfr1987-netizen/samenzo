# Supabase

Deze map bevat de actieve Supabase-configuratie, migraties, seedbestanden en
testplaceholder voor SAM&ZO.

Belangrijke afspraken:

- Bewerk geen al gepushte migraties; maak een nieuwe migratie met de Supabase CLI.
- Houd RLS aan voor publieke tabellen.
- Gebruik geen service-role in frontendcode.
- Seeddata is bedoeld voor ontwikkeling en regressiecontrole, niet als productiedata.
